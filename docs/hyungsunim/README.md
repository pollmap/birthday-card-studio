# 형수님 생일 카드

주소: https://pollmap.github.io/birthday-card-studio/hyungsunim/

문구: 형수님, 생일 축하드립니다! 서명 없음.
치이카와·하치와레가 케이크를 받치고 우사기가 함께 축하한다. 배경은 가랜드, 풍선, 리본 선물, 도트와 하트로 구성했다.

기존 카드 자산을 재사용하되 family.css/family.js에서 개별 연속 이동, 다리 흔들기, 부드러운 착지와 공동 케이크 받침을 구현했다. 포즈 프레임을 순간적으로 교체하지 않는다. 손·받침·케이크는 동일한 holding-team 부모에 연결해 움직이는 동안 상대 위치가 바뀌지 않는다. 클릭/터치 폭죽과 재생, 소리 켜기, 링크 복사를 지원한다. 동작 줄이기와 백그라운드 중지 적용.

검증: JS 구문 검사, 390×844/320×568 레이아웃과 제목·무대·버튼 비겹침, 3캐릭터 존재. 5.5초 런타임 샘플 327개에서 run/lift/done 전환, 연속 프레임 수직 이동 최대 약 2.88px 및 케이크/받침 상대 위치 일정함을 확인. 이는 해당 브라우저 실행의 관측값이며 모든 기기 성능을 보증하지 않는다. 실제 iPhone Safari는 미검증.

공유 이미지 og-v1.png는 og.html을 1200×630으로 렌더링했다. 기존 네 카드는 수정하지 않았다.
