# 재연님, 발표 파이팅!

주소: https://pollmap.github.io/birthday-card-studio/jaeyeon/

발표 응원 카드. 오리지널 응원단 3인방(말랑이·삐약이·개굴이)을 SVG 부위별(팔·발·눈·입·새싹·머리띠)로 그려 CSS로 움직인다. 외부 이미지·라이브러리 없음(폰트만 Google Fonts Jua).

- `buddies.js`: 캐릭터 SVG 생성
- `cheer.js`: 연출 타임라인, 폭죽 캔버스, 게이지, 효과음(기본 꺼짐)
- `cheer.css`: 레이아웃과 모든 동작
- `og.html` → `og-v1.png`(1200×630): headless Chrome으로 렌더

연출: 빼꼼(대기) → 달려와서 등장 → 제자리 점프 "재연님!!" → "발표 찢자!" 도장 + 화면 흔들림 → 폼폼 응원 + 말풍선 → 깃발 "발표 대성공!!" + 상승 화살표 "쭉쭉!" + 파도 점프·공중제비 + 불꽃놀이 → 그루브 반복.
완료 후 캐릭터를 톡톡 누르면 반응하고 파이팅 게이지가 차며, 100%가 되면 "재연님 발표 대성공!!" 메가 응원이 터진다.

검증: 390×844, 375×667, 320×568, 844×390에서 가로 넘침·세로 스크롤 없음, 무대·버튼 영역 분리 확인. 실제 iPhone Safari는 미검증.
